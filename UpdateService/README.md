# PerformanceHUD update service

This directory contains the service and publishing tools for PerformanceHUD’s official in-app updates. Update metadata and app packages are signed and verified before installation.

To update the app, choose **Check for updates** in its menu. See the [installation guide](../docs/INSTALL.md#updating-or-removing-the-app) for details and [Privacy & access](../docs/PRIVACY_AND_ACCESS.md#app-updates) for information about update requests.

Building and running PerformanceHUD from source does not require deploying this service. The release-publishing tools are for maintaining the official update service.
